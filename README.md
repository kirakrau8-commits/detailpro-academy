# DetailPro Academy

Plataforma educacional de estética automotiva em HTML, CSS e JavaScript puro.

## O que já está incluído
- 8 trilhas de aprendizagem com aulas teóricas.
- Progresso das aulas salvo localmente no navegador (localStorage).
- Biblioteca inicial com 4 videoaulas públicas do YouTube.
- Lista de produtos Vonixx organizada por categoria.
- Glossário e quiz de conhecimentos.
- Layout responsivo para celular e computador.
- Perfil visual fictício "Aluno demonstração". Não existe cadastro, senha, autenticação ou banco de contas.

## Executar localmente
Abra `index.html` no navegador. Para publicar com GitHub Pages, habilite Pages nas configurações do repositório e selecione a branch `main` e a pasta raiz.

## Catálogo Vonixx
O site está preparado para carregar `catalogo-vonixx-2024.pdf` na raiz do projeto. O PDF original (47 páginas) ainda precisa ser enviado como arquivo binário ao repositório. Até isso acontecer, os botões/visualizador do catálogo não terão o PDF para abrir.

## Observação sobre privacidade
A conta fictícia é apenas um rótulo visual de demonstração. O progresso fica no armazenamento local do navegador e não é sincronizado entre dispositivos.
